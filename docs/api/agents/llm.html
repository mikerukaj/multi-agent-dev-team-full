agents.llm

Claude request settings and helpers shared by the PM, Coder and QA agents.

Every model call goes through one ModelCaller per agent (specs/003-production- hardening/plan.md, Summary 1), so reply validation, usage accounting and, as 003 adds them, retries, circuit breaking, prompt caching, cost and tracing are written once.

EFFORT_LEVELS = ('low', 'medium', 'high', 'xhigh', 'max')
LARGE_MODEL = 'claude-sonnet-5-5'
SMALL_MODEL = 'claude-haiku-5-5'
MODEL_CAPABILITIES = {'claude-sonnet-5-5': {'fallbacks': True, 'efforts': ('low', 'medium', 'high', 'xhigh', 'max'), 'mid_conversation_system': True}, 'claude-haiku-5-5': {'fallbacks': False, 'efforts': ('low', 'medium', 'high', 'xhigh', 'max'), 'mid_conversation_system': True}}

What each known model supports (research R8). Haiku 5.5 has no server-side refusal fallback.

Check an agent's settings against its model (FR-225b); return warnings.

A model missing from MODEL_CAPABILITIES is allowed with a warning, and no capability is assumed.

Read a *_USE_FALLBACKS value; unset (or empty) means the model's default.

def cache_marker(ttl: str) -> dict | None:

The cache_control marker for PROMPT_CACHE_TTL (None when off).

Every marker in a request uses the same TTL, so the API's "longer TTL first" rule never applies (research R7).

def system_blocks(text: str, ttl: str) -> str | list[dict]:

The system value: one cache-marked text block, or the plain text when off.

def stable_blocks(stable: list[str], instruction: str, ttl: str) -> list[dict]:

User content: the parts that repeat across calls, then this call's instruction.

The marker goes on the last stable part, so the repeated prefix is billed at the cache-read rate on later calls (FR-225).

class ModelReply:

The outcome of one ModelCaller.call.

data is set only for a structured reply that parsed and passed validation; problems lists why it did not. refusal is the refusal message when the model declined. response is the SDK message (None when no call was served).

def call( self, request: dict, reply_type: type | None = None) -> ModelReply:

Send request and return the reply, validated against reply_type.

With reply_type=None the raw response is returned for the caller to read (the Coder's tool-using turns). A refusal is reported, never validated. The call goes through the run's anthropic:<model> guard (retries and circuit breaker); when the guard gives up, a cached reply to the identical request is served if it still validates, otherwise ModelReply.failure says why. It never raises for a model-service failure.

def operation_name(reply_type: type | None) -> str:

What a model call was for, as cost.audit groups it: the reply type's name.

A call with no reply type is a tool-using loop turn (the Coder's build and fix steps).

def served_model(response, request: dict) -> str:

The model that served a response (a fallback may differ from the one requested).

def request_summary(request: dict) -> dict:

What an llm span shows of a request: its shape, never the prompts themselves.

def llm_outputs(reply: ModelReply) -> dict:

What an llm span shows of a reply, with LangSmith's usage_metadata.

def read_reply(response, reply_type: type | None) -> ModelReply:

Turn one SDK response into a ModelReply, validating it against reply_type.

def usage_of(response) -> orchestration.state.TokenUsage:

The response's token counts as a TokenUsage; missing cache counts are 0.

def parse_reply(response, reply_type: type) -> tuple[dict | None, str, list[str]]:

Join the reply's text, parse it as JSON and validate it against reply_type.

Returns (data, text, problems); data is None whenever problems is not empty.

def output_problem(problems: list[str]) -> str:

Describe why a structured reply can't be used, for an agent's error message.

def failure_message(failure: orchestration.state.DependencyFailure) -> str:

Describe a model call that could not be served, for an agent's error message.
