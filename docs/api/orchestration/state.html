orchestration.state

Shared LangGraph state that the PM, Coder and QA agents read and write.

Every value is a TypedDict, a Literal or a plain JSON type, so any state converts to JSON with json.dumps and back without loss (specs/001-autonomous-dev-team/data-model.md, "Increment 2: Shared Team State").

Increment 3 adds QA's test results and findings, the Coder's self-reflection and fix rounds, the Coder <-> QA iterations, QA's final report, the A2A exchange log, and the JSON-only request payloads that cross the A2A broker (QAContext, FixRequest, FinalReportRequest). The payloads live here, not in an agent module, so neither agent imports the other (specs/002-qa-feedback-loop-mcp/data-model.md).

Production hardening (003) adds per-agent usage and cost, structured dependency failures, resume history, the run summary, and one reply TypedDict per model-facing JSON schema, so every model output is validated before it is used (specs/003-production-hardening/data-model.md).
